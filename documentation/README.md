# 🚀 Deploying TheCore Website on Raspberry Pi

This guide explains how to deploy **TheCore** website onto a Raspberry Pi using **GitLab Runner**, **Docker**, and **GitLab CI/CD**.

---

## 📋 Prerequisites

- Raspberry Pi (recommended: Raspberry Pi 4 or 5)
- MicroSD card (16GB+)
- Raspberry Pi OS Lite
- Access to your GitLab repository

---

## 🧰 Step-by-Step Setup

1. **Flash Raspberry Pi OS Lite**

   - Download from the [Raspberry Pi Imager](https://www.raspberrypi.com/software/)
   - Flash the SD card and boot up your Pi
   - (Optional: [Follow this tutorial](link_here))

2. **Connect to your Raspberry Pi**
   ```bash
   ssh pi@<raspberry_pi_ip>
   ```
